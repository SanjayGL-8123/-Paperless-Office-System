# 🌿 Paperless Office System

A minimal client-side digital document manager — save named documents with notes, browse, and delete them, all without a backend server.

---

## 📁 Files

| File | Purpose |
|------|---------|
| `index.html` | App UI — input fields and document list |
| `style.css` | Styling — green eco-themed card layout |
| `script.js` | JavaScript — save, list, and delete documents using `localStorage` |

---

## 🌟 Features

- Save document **name + note** with a timestamp.
- Browse all saved documents in a live list.
- Delete individual records instantly.
- **100% client-side** — no server needed; data persists via browser `localStorage`.
- Eco-themed messaging: *"Reduce paper. Save trees. Work digitally."* 🌱

---

## 🚀 How to Run

Open `index.html` directly in your browser.

---

## ⚙️ Tech Stack

- **Frontend:** HTML5, CSS3, Vanilla JavaScript, `localStorage` API
